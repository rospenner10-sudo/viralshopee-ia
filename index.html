O feed precisa devolver JSON como uma lista de produtos ou um objeto com a chave products. Campos aceitos: name/title, price, category, rating, sales/sold, commission, affiliate_url/link, image_url/image, benefits/features. A API real da Shopee não é conectada automaticamente por este campo: use apenas integração/endpoint que você esteja autorizado a acessar.
